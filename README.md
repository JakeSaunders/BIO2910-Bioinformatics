# Unit 02 — Basics of R and R Studio

## Unit 02 learning objectives

By the end of this unit you should be able to:

- Run R code and read its output
- Assign objects with `<-` and describe an object's class
- Call a function, set its arguments, and read its help page with `?`
- Subset a data frame with `[ , ]` and with `$`
- Read a CSV into R from a URL
- Build and customize the four base graphics: `hist()`, `barplot()`, `boxplot()`, `plot()`
- Tell the difference between a warning and an error, and start troubleshooting either
