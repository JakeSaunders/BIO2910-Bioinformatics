

## Completing and Turning in Colab Assignments

**Before the first R class:** You need a free Google account. Your `kean.edu`
account will **not** work. A personal Gmail account will, but if you'd rather not attach your personal email to coursework, [create a new
Google account](https://support.google.com/mail/answer/56256?hl=en) just for this
class. It does not have to use your real name. If you can't make an account, see
me (there are other options, but they're more complicated).

1. Click the **Open in Colab** button for the assignment.
2. Do this *immediately*, before you type anything. **File → Save a copy in Drive.**  Notebooks opened from GitHub are read-only — anything you write before you make a copy is lost when you close the tab (you can lose hours of work if you don't do this).
3. Rename your copy: **File → Rename**, and change `Copy of ...` to `Lastname_02-01`. This is the file you submit.
4. Check that the top-right corner says **R**. If it says Python, go to **Runtime → Change runtime type → R**.
5. Follow the directions in the assignment.
6. **Runtime → Restart session and run all** — this clears any previous code blocks that have been run and runs everything from start from a clean start. If it
   breaks here, it was only working by accident and you need to fix it before you submit. 
7. When finished **File → Print → Save as PDF** and **File → Download → Download .ipynb**
8. Upload both the PDF and .ipynb to Canvas.

- The first time you open Google Colab, click on the gear icon in the upper right corner to open settings
    - Click on **AI Assistance** in the menu on the left-hand of the settings popup box.
    - Make sure that the check boxes appear as below:
        - [Unchecked] Show AI-powered inline completions
        - [Unchecked] Consented to use generative AI features
        - [Checked] Hide generative AI features
    - Click **Save**

    ***Note on Generative AI use:*** I'm not banning AI. In fact, I encourage you to use it when you're stuck or don't understand a concept. What I'm instructing you to to is turn off is the autocomplete that finishes your code before you've decided what you want to write. The point is that *asking* for help stays a decision you make, so you're using AI as a learning tool rather than as a substitute for thinking. 
    
    To be  clear about what that means for your grade: In this course, I grade heavily for completion and effort on assignments (e.g. you get the bulk of the points for showing that you made the effort to complete the assignment and following directions). Since any of the free generative AI programs can 
    complete every assignment in this course in a few minutes, if the work you turn in resembles the generate AI's answer space-for-space and character-for-character that is definiationally below average effort and minimum successful completion which is, definitionally C work. 
    
    **Disclosure is required.** Also if you use large chunks of code produced by generative AI (for the purposes of this course defined as more than 1 line of code) you need to disclose what program generated the code in a coding commit or you have plagiarized the work you have turned in (which is a voliation of Kean's Academic Integrity policy).
